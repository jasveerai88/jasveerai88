# Hi, I'm Jasveer

I build free, local-first tools for faceless and AI video creators — from measured failure data on real channels, not opinions.

## Featured
**[Faceless QC Lite](https://github.com/jasveerai88/faceless-qc-lite)** — free pre-upload checker for faceless videos: loudness, dead air, black frames, caption speed, resolution. Runs 100% on your machine. MIT.

Real catch: it flagged one of my own videos at −21.6 LUFS (target −14) before upload.

**[Payout Tracker](https://github.com/jasveerai88/payout-tracker)** — a balance is not money: REALIZED vs PAYABLE vs STUCK payouts, fees and FX in CAD + INR.

**[Demand Miner](https://github.com/jasveerai88/demand-miner)** — finds buyers hiding in public posts, offline, sellers filtered out.

**[Caption Toolkit](https://github.com/jasveerai88/caption-toolkit)** — caption speed check + fix + SRT↔VTT convert.

**[Shorts Packager](https://github.com/jasveerai88/shorts-packager)** — Shorts title fitter for the 100-char rule — hashtags that fit stay in the title, the rest go to the description.

**[Thumbnail Checker](https://github.com/jasveerai88/thumbnail-checker)** — pre-upload thumbnail resolution, aspect ratio, and filename checks.
